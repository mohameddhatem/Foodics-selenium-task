# Foodics Selenium Task

This repository contains a Selenium-based test automation project designed to interact with the Foodics Pay2 API and perform a series of actions on an e-commerce website (such as adding products to the cart).

## Project Overview

The goal of this project is to create automated tests for the **Foodics Pay2** API and an e-commerce website that allows adding video games to the cart using Selenium and Java. The tests ensure functionality such as filtering products by price, adding items to the cart, and verifying price and product attributes.

## Features

- **Selenium WebDriver Automation** for web interactions (filtering products, adding to the cart).
- **Price Extraction** to filter products below a certain price range.
- **Explicit Waits** for elements to load before performing actions.
- **Actions Class** for simulating user mouse movements and interactions.
- **Page Object Model** design for cleaner and more maintainable code.
